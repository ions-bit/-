# GPT Web Skin — ChatGPT UI v4.1

A ChatGPT-inspired visual layer for SillyTavern, based on the original Claude Web layout engine.

## v4.1

- Refined ChatGPT-style sidebar rhythm and recent-chat states
- Minimal centered top context/model presentation
- 768px reading column with cleaner assistant/user message hierarchy
- Compact hover-only message actions
- Refined floating composer with focus states
- Stronger send/stop states
- ChatGPT-like code blocks, tables, and typography
- Responsive mobile composer and sidebar
- Keeps the existing SillyTavern generation and message actions intact

## Install

1. Copy the contents of this directory into your SillyTavern extension directory.
2. Reload SillyTavern.
3. Enable the GPT Web Skin extension.

## Compatibility note

This project intentionally keeps the original internal JavaScript selectors and compatibility layer where changing them could break SillyTavern behavior. The visible UI is re-themed through the GPT visual layer.
