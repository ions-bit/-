# GPT Web Skin — ChatGPT UI

这是一个基于 SillyTavern 的 GPT / ChatGPT 风格界面主题扩展。

## 项目定位

本项目保留原扩展的消息发送、生成、切换以及 SillyTavern 兼容逻辑，主要重做前端视觉层与布局，使整体体验尽可能接近现代 ChatGPT Web。

## 主要特性

- ChatGPT 风格左侧导航栏与最近对话列表
- 中央窄内容列
- 助手消息阅读式排版，无传统气泡
- 用户消息轻灰圆角气泡
- 独立悬浮 Composer 输入区域
- GPT 风格模型 / 工具区域视觉
- Markdown、代码块、引用、表格优化
- 消息复制、编辑、重试等操作按钮重新排版
- 桌面端与移动端适配
- 日间 / 夜间主题
- 尽量保持 SillyTavern 原有业务逻辑不变

## 安装

### 方式一：SillyTavern 扩展安装

将本仓库作为扩展仓库安装，或者将项目目录复制到 SillyTavern 的第三方扩展目录。

### 方式二：手动安装

将整个 `gpt-web-skin` 目录复制到 SillyTavern 的第三方扩展目录，然后重新加载页面。
